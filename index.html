Verification marks. Inside an entry, every statement that rests on an external source carries a small mark, and hovering it shows the source and the date it was consulted. ✓ is a fact confirmed in the source; ? is an inference, a conclusion of the note and not a fact; ✗ is not verified, which includes what was checked and the source did not support.
