# Disaster Law and Policy — course wiki

Public wiki for the elective **Disaster Law and Policy: International and
Comparative Perspectives** (FGV Direito Rio, 30h, 2026.2), taught in English by
Leonardo Carrilho.

## Published session by session

Pages appear here as each class is taught. The distilled analysis of a reading is
the work the class exists to do with the students, so it is not published before
the class happens.

## What is here

Session pages, plus entries for concepts, authors, texts, case law and
legislation, with a tag index and a graph view. Start at `index.html`.

## What is not here

The working repository — sessions not yet taught, mirrors of the course reader,
the bibliography and working notes — is local and is never published.
